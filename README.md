# Online Bookstore SQL Analysis

## Project Overview

This SQL project analyzes sales data from an online bookstore to uncover customer purchasing behavior, revenue trends, and ordering patterns. The analysis was performed using PostgreSQL and SQL queries to generate meaningful business insights from transactional data.

## Business Objective

* Analyze bookstore sales performance.
* Identify top customers and bestselling books.
* Understand customer ordering patterns.
* Generate business insights using SQL queries.
* Measure overall revenue performance.

## Tools Used

* PostgreSQL
* PGAdmin
* SQL

## Skills Demonstrated

* SELECT Statements
* WHERE Clauses
* DISTINCT
* ORDER BY
* LIMIT
* Aggregate Functions
* GROUP BY
* JOINS
* Data Analysis

## Key Analysis Performed

### Customer Analysis

* Identified top spending customers.
* Analyzed customer purchase behavior.
* Evaluated customer contribution to revenue.

### Book Analysis

* Identified most ordered books.
* Filtered books based on genre.
* Ranked books by price.

### Revenue Analysis

* Calculated total revenue generated from all orders.
* Analyzed sales trends using aggregate functions.

## Sample Business Questions Solved

1. Who are the top spending customers?
2. Which books generate the highest sales?
3. Which genres are most popular?
4. What are the most expensive books available?
5. How much total revenue has the bookstore generated?
6. Which books receive the highest number of orders?

## Key Insights

* Revenue is concentrated among a small group of high-value customers.
* Certain books consistently drive a large share of sales.
* Popular genres contribute significantly to overall revenue.
* SQL can be effectively used to transform raw transactional data into actionable business insights.
